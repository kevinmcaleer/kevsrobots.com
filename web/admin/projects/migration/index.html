Editor Migration

Moving existing projects to the new project editor (issue #273). Nothing on this page changes a project until you press a button, and the only change it can make is appending a Bill of Materials table.

Bill of Materials not in the text yet 0

These projects were saved before the Bill of Materials lived in the Markdown. Their owners see an "Insert BOM table" bar in the editor. This button does the same for all of them: it appends the table to the end of the text, under a <!-- … generated … --> comment, and leaves "last updated" alone.

Every project with BOM rows has its table in the text.

Open-and-save check

Loads each project's Markdown into the editor here in your browser (the same editor bundle the project editor uses) and reads it back, without saving anything. A project passes when the text comes back unchanged. The editor also writes three things into a project's text the first time it is opened: Bill of Materials totals, a Code repository section for a stored repository link, and a Videos section for stored videos. Those are listed as expected, not as failures, as is text saved with Windows line endings, which the editor keeps as plain \n (it renders the same).
