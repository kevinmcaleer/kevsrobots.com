{%- comment -%} How many usability problems a test with n people finds, from Jakob Nielsen's model N(1 - (1 - L)^n). See docs/course_widgets.md. {% include five_users.html %} {%- endcomment -%}

This calculator needs JavaScript. By hand: with L = 0.31 (each tester finds about 31% of the problems), n testers find 1 - (1 - 0.31) to the power n of them. Five testers find about 84%.
