{% comment %} One learning pathway as a card: cover, title, course count, total time, level range and a short description. On desktop (a fine pointer that can hover), hovering or tabbing into the card opens a panel across the full width of the card grid, the same way the blog cards do: the full description on the left and the pathway's courses as rows on the right (level, length, lessons), each linking to its course. Long pathways show six rows and a link to the rest. Touch devices never see the panel; the card opens the pathway page. Usage: include pathway_card.html pathway=pathway (pathway = a page from site.data.pathways, see _plugins/pathways.rb).
