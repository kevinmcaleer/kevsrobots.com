outcomes:
- Build a jointed robot model in Snakie from boxes, tubes and balls
- Choose the right joint type, axis and limits for each moving part
- Save named poses and play them back as a looping motion
- Bind servo pins to joints and drive the 3-D robot from MicroPython
- Export a motion as MicroPython code and the robot as a URDF file
- Render a short video of your robot moving
