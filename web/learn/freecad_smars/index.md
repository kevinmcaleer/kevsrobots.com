outcomes:
- Navigate the FreeCAD 3D view with the mouse, navigation cube and keyboard shortcuts
- Build constrained, centred sketches and turn them into solids with Pad and Pocket
- Hollow and round a part with Thickness and Fillet
- Use external geometry, datum planes, Mirror, Revolve and Polar Pattern on a real
  robot chassis
- Export a model as an STL file and check it in a slicer before printing
prerequisites:
- Basic computer skills such as working with files, folders and menus
- No previous CAD or 3D printing experience needed
- Helpful but not required, Introduction to FreeCAD for Beginners
you_need:
- A computer that can run FreeCAD 0.21 or newer (Windows, Mac or Linux)
- A mouse with a middle button is recommended
- Optional, a 3D printer with at least a 120mm x 100mm build area and PLA filament,
  or access to a makerspace or print service
