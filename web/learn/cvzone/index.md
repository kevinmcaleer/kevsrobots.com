- Set up a Python virtual environment with OpenCV, MediaPipe and CVZone on a Raspberry
  Pi
- Capture live video from a USB webcam or a Raspberry Pi camera module
- Detect faces and use their position and size in your own code
- Track a hand, count raised fingers and measure a pinch distance
- Find body landmarks and measure the angle at a joint
- Overlay live text and feedback on the video, and build a repetition counter

  course

- A screen, keyboard and mouse, or remote desktop access, because the examples open
  a video window
- An internet connection for the installs and for the one-off model downloads
