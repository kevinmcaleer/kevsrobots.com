description: AI can write the code in minutes, so the hard part now is building the
  right thing. Learn the five design thinking modes (empathise, define, ideate, prototype,
  test) and how to use each one with AI-assisted, vibe coded software and robots,
  while you build a Classroom Plant Helper with a Raspberry Pi Pico.
level: beginner
course_duration: 1h 38m
lesson_count: 15
first_lesson: 00_intro.html
quiz_total: 42
video: 90pPahgU9JM
outcomes:
- Find out what real people need by watching and interviewing them, instead of asking
  an AI to guess
- Turn what you learn into a point of view, How Might We questions and a brief an
  AI assistant can work from
- Generate lots of ideas, then choose one with impact and effort in mind
- Build quick prototypes, from cardboard and Wizard of Oz fakes to vibe coded MicroPython
- Check AI-written code for made-up libraries, wrong pins and missing tests, and test
  it with real users
- Run the whole loop again, and know when to iterate, pivot or stop
prerequisites:
- None for the design lessons. For the build lessons, Learn MicroPython - The basics
  helps
- Helpful, Getting Started with Snakie and Git for Beginners
you_need:
- Paper, sticky notes, pens and some cardboard
- An AI coding assistant, such as the chat pane in Snakie, Claude, ChatGPT or GitHub
  Copilot
- For the build, a Raspberry Pi Pico or Pico W, a capacitive soil moisture sensor,
  red, amber and green LEDs with 220 ohm resistors, a piezo buzzer, a push button,
  a breadboard and jumper wires
- A plant in a pot, and a real person to design for
