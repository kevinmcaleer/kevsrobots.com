- Explain that a vault is just a folder of plain Markdown files, and create one
- Write notes that link to each other with wikilinks, and follow backlinks
- Organise notes with tags and properties
- Track jobs with task checkboxes, and lay out a project on a Canvas
- Build a Base that turns your notes into a sortable table
- Read the graph view to find orphaned notes and clusters

- No Obsidian or Markdown experience is needed

- A Windows, macOS or Linux computer, or a Raspberry Pi running Raspberry Pi OS
- An internet connection to download Obsidian
- Optionally, a robot or electronics project to write about
