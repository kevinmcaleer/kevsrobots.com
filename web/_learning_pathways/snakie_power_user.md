Already comfortable in [Snakie](https://app.snakie.org)? This pathway is for makers who want to get more from it. First you'll learn the tools that make writing MicroPython faster and safer: smart autocomplete, hover help, linting, one-click refactors, packages, compiling to `.mpy` and Git. Then you'll use the Part Editor to add your own sensors, breakouts and microcontroller boards, complete with drivers, built-in help and their own blocks.

New to Snakie? Take the [Start with Snakie](/learn/learning_pathways/snakie.html) pathway first.
